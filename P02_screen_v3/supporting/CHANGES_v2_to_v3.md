# P02 screening: changes from v2 to v3 (approved for freeze and release; not yet released)

Baseline: the released P02-screen-v2 text (SHA-256 `754d83f8cc16f472673fcd8cc695882ff07731acddf01d63f8211409062f734d`, tag P02-screen-v2, commit 8435ff9, DOI 10.5281/zenodo.23883100).

Rows R1-R3 are the three changes Mahmood authorized. Every other row is tighter than v2 or neutral; **no v2 gate is loosened**. "Tighter" means that it can only remove candidates that v2 might have passed, or add a check. Rows marked **[Dn]** were decided on 2026-11-02 by dispatch, under Mahmood's delegation (`DECISION_v3_2026-11-02.md`).
