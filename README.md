# Use-case pre-registrations (allmeta F1000 software papers)

Each folder (`P13/`, `P14/`, …) holds one pre-registration, `PREREG_Pnn_usecase.md`. It is written **before** any data extraction or
analysis of a field-specific use case for the corresponding allmeta software paper.

Each pre-registration is published as its own GitHub **release**, which gives it a server-side timestamp. Zenodo archives every release with a DOI,
which is cited in the paper. Git commit dates are not used as evidence of time.

A pre-registration states: the chosen published meta-analysis (DOI), the outcome, the exact analysis, the reproduction gate (the original pooled
estimate that must be reproduced first) and what will count as a "new" versus a "robust" finding.
